# 科学可视化（Web）

静态 AP 科学可视化站点：生物 / 微积分 BC / 物理 C 力学与电磁（含预备层）。

## 本地预览

```bash
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/index.html
```

GitHub Pages：开启 Pages（根目录），已提供 `404.html`。

## 功能

- 知识点页（自学向：直觉 / 循序展开 / 例题 / 自测 / 小结）
- 单元练习（专项图示、共享刺激、符号/数值验算、来源署名）
- 3D 知识图谱（球面分层布局 + 边中点关系）
- 公式表、历年真题索引（College Board FRQ **仅外链**）
- 内容来源：`#/credits`
